自用项目，实现了一个简单的注入器

源自Perxenic-Acid大佬的SSMT4子项目（https://github.com/Perxenic-Acid/SSMT-Native），因为注入器效果确实很好，使用ai修改/添加了CLI薄层，独立出来使用，在此特别致谢

为符合上游开源协议在此开源，看心情同步上游

使用方法：命令行打开，--help查看所有可用参数。主要是“--inject”和“--launch”

由于项目是一个内存注入器，必然会触发杀毒软件的主动防御等功能。release的预构建没有安全承诺。你可以选择自行审查源代码并构建。有一个构建脚本，但是我也没有审查过，可以酌情使用
